# Atlassian Provider

Use the Atlassian provider to manage Atlassian Cloud resources.

Organization resources authenticate with an Atlassian organization API key.
Supply it as `admin_api_key` or, preferably, through the
`ATLASSIAN_ADMIN_API_KEY` environment variable.

The `site_url`, `email`, and `api_token` settings form an independent credential
set reserved for Jira and Confluence APIs. If one of those settings is used,
all three must be configured.

### Optional

- `admin_api_key` (String, Sensitive) Atlassian organization API key used for Cloud Admin APIs. May also be set with ATLASSIAN_ADMIN_API_KEY.
- `api_token` (String, Sensitive) Atlassian API token. May also be set with ATLASSIAN_API_TOKEN.
